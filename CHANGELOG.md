# Changelog

## 0.1.0-dev.1

- Add native and browser HTTP transports with cancellation and streamed responses.
- Add named/typed client factories, transport rotation and response-aware draining.
- Add multipart/forms/stream bodies, bounded readers and typed request metadata.
- Add opt-in deadlines, retries, concurrency, circuit breaking, failover and hedging.
- Add token refresh coordination, cache validation, diagnostics and progress events.
- Add consumer testing controller, resumable downloads and host-scoped cookies.
- Add SSE, WebSocket, native sockets and resource state APIs.
- Add a separate Flutter notifier package and focused feature imports.
- Use compact typed byte buffers; exclude development artifacts from publication.
- Include MIT license, examples, architecture, compatibility and release guidance.

Development preview; publication remains disabled pending release validation.
