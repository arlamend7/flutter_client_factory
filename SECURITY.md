# Security reporting

Do not put credentials, personal data, or exploitable vulnerability details in a
public issue. Use GitHub's **Security → Report a vulnerability** option when private
reporting is enabled for this repository. If it is unavailable, contact the
maintainer through their public GitHub profile to arrange a private channel before
sending sensitive details: https://github.com/arlamend7.

Include the affected package/version, platform, a minimal reproduction, impact,
and any proposed mitigation. No response-time commitment is implied.

The 1.x release line is the current maintenance target. Use supported Dart/Flutter
SDKs. Review `doc/platforms.md` for browser restrictions and intentionally limited
cookie behavior. TLS certificate validation must remain enabled in production.
